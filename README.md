## 프로젝트 소개

Coding Problem Archive는 프로그래밍 학습 및 평가를 목적으로 직접 출제한 알고리즘과 프로그래밍 문제를 제공하는 공개 문제 아카이브입니다.

단순한 문법 학습부터 알고리즘 설계, 문제 해결, 프로그래밍 언어의 구조적 이해 및 제한된 환경에서의 구현 능력 평가까지 다양한 수준의 문제를 제공합니다.

모든 문제는 교육적 활용을 고려하여 설계되며, 동일한 주제라도 난이도에 따라 서로 다른 조건과 요구사항이 적용될 수 있습니다.

## 프로젝트 목표

- 프로그래밍 기초 문법 및 구현 능력 향상
- 알고리즘 설계 및 문제 해결 능력 향상
- 프로그래밍 언어별 특성에 대한 이해
- 제한된 환경에서의 창의적인 문제 해결
- 수기 코딩 및 실습 평가에 활용 가능한 교육 자료 제공

## 지원 언어

| 언어 | 지원 여부 |
|---|---|
| Python | Supported |
| C | Supported |
| C++ | Planned |
| Java | Planned |

문제에 따라 지원 언어가 달라질 수 있으며, 각 문제의 지원 언어는 해당 문제 문서에 명시됩니다.

## 난이도 체계

| 난이도 | 설명 |
|---|---|
| Easy | 기본 문법, 조건문, 반복문 및 기초 구현 능력을 평가합니다. |
| Normal | 알고리즘 응용, 예외 처리 및 효율적인 구현 능력을 평가합니다. |
| Hard | 제한된 자료구조, 함수 및 실행 환경에서의 문제 해결 능력을 평가합니다. |
| Extreme | 고급 알고리즘, 언어 명세 분석 및 복합적인 문제 해결 능력을 평가합니다. |

난이도는 본 프로젝트의 자체 기준이며, 외부 코딩 평가 서비스의 난이도 체계와 일치하지 않을 수 있습니다.

## 문제 구성

각 문제는 다음 항목을 포함할 수 있습니다.

- 문제 번호 및 제목
- 지원 프로그래밍 언어
- 난이도
- 문제 설명
- 입력 설명
- 출력 설명
- 입출력 예제
- 제한사항
- 채점 기준
- 모범 답안 및 해설

## 평가 방식

본 프로젝트의 문제는 다음과 같은 환경에서 활용할 수 있습니다.

- 수기 코딩 평가
- 프로그래밍 실습
- 알고리즘 학습
- 온라인 저지 시스템
- 교육기관의 자체 평가
- 개인 학습 및 역량 확인

수기 코딩 문제의 경우 실제 실행 환경을 전제로 하는 문제와 평가 기준이 다를 수 있습니다.

## 문제 풀이 유의사항

1. 문제의 설명 및 제한사항을 충분히 확인한 후 풀이를 작성해야 합니다.
2. 문제에 명시된 지원 언어를 사용해야 합니다.
3. 정상적인 실행 결과뿐만 아니라 제한사항 준수 여부도 평가 대상이 될 수 있습니다.
4. 일부 문제는 일반적인 구현 방법과 다른 방식의 해결을 요구할 수 있습니다.
5. 공개된 입출력 예제에만 의존하지 않고 문제의 전체 규칙을 만족해야 합니다.

## 모범 답안

일부 문제의 모범 답안 및 해설은 학습과 검증을 목적으로 제공될 수 있습니다.

제공되는 모범 답안은 가능한 풀이 방법 중 하나이며, 동일한 조건을 만족하는 다른 풀이도 정답으로 인정될 수 있습니다.

## 기여 및 오류 제보

문제의 오류, 모호한 설명, 잘못된 입출력 예제 및 개선 사항은 GitHub Issues를 통해 제보할 수 있습니다.

새로운 문제, 대체 풀이 및 기존 문제 개선에 대한 Pull Request를 환영합니다.

모든 기여 사항은 검토 후 반영됩니다.
