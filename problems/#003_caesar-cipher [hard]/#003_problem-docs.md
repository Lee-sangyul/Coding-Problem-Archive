# #003 암호화 (Caesar Cipher)

**Difficulty: Hard | Language: Python, C**

## 문제 설명

나는 기존 문자열 암호화 시스템을 개선하는 업무를 맡고 있다.

그러나 기존 시스템에서 사용할 수 있었던 일부 함수, 자료구조 및 라이브러리의 사용이 제한되었다.

당신은 제한된 프로그래밍 환경에서 각 알파벳을 m칸씩 이동시키는 암호화 시스템을 구현해야 한다.

알파벳의 범위를 벗어나는 경우 순환하여 이동하며, m이 음수인 경우 반대 방향으로 이동한다.

모든 제한사항을 준수하여 문자열을 암호화하는 프로그램을 작성하시오.

## 입력 설명

첫 번째 줄에 이동하는 칸 수 m을 입력받는다.

두 번째 줄에 암호화할 문자열 S를 입력받는다.

입력 자료구조의 구체적인 형식은 제한하지 않는다.

## 출력 설명

문자열 S의 알파벳만 m칸씩 이동시켜 암호화한 결과를 출력한다.

출력 자료구조의 구체적인 형식은 제한하지 않는다.

## 공통 제한사항

- m의 범위는 -1,000,000,000 이상 1,000,000,000 이하이다.
- 문자열의 최대 길이는 20,000자이다.
- 변수는 최대 10개까지 사용할 수 있다.
- 함수의 매개변수 및 반복문에 사용되는 변수도 변수 개수에 포함한다.
- 입출력 목적을 제외한 문자열 및 배열의 사용을 금지한다.
- 문자 코드에 기반한 직접적인 산술 연산을 금지한다.
- 문자를 한 칸씩 m번 이동시키는 방식을 금지한다.
- 메모리에 직접 접근하여 데이터를 수정하는 것은 허용한다.
- 전역변수 사용을 허용한다.
- 암호화 기능은 반드시 sol() 함수로 구현한다.
- 영문 알파벳의 대소문자를 유지한다.
- 숫자, 공백 및 특수문자는 변경하지 않는다.
