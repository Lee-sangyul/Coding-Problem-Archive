# #001 암호화 (Caesar Cipher)

**Difficulty: Easy | Language: Python, C**

## 문제 설명

나는 특정 문자열을 암호화하는 업무를 맡고 있다.

여기서 사용하는 암호화 기법은 각 알파벳을 m칸씩 옆으로 이동시키는 것이다.

단, 알파벳 이외의 숫자, 공백 및 특수문자는 그대로 유지한다. 알파벳의 범위를 벗어나는 경우 처음으로 돌아가며, 대소문자는 유지한다.

예를 들어, m이 2이고 `ABC1234!`를 입력받았다면 `CDE1234!`를 출력하고, m이 3이고 `XYZ!!`를 입력받았다면 `ABC!!`를 출력한다.

이러한 방식으로 문자열을 암호화하는 프로그램을 작성하시오.

## 입력 설명

첫 번째 줄에 문자열의 길이 n과 이동하는 칸 수 m을 공백으로 구분하여 입력받는다.

두 번째 줄에 암호화할 문자열 S를 입력받는다.

## 출력 설명

문자열 S의 알파벳만 m칸씩 이동시켜 암호화한 결과를 출력한다.

## 입출력 예제 1

### 입력

```
12 1
Hello world!
```

### 출력

```
Ifmmp xpsme!
```

## 입출력 예제 2

### 입력

```
8 2
ABC1234!
```

### 출력

```
CDE1234!
```

## 입출력 예제 3

### 입력

```
5 3
XYZ!!
```

### 출력

```
ABC!!
```

## 제한사항

- m은 양의 정수이다.
- 대소문자를 유지해야 한다.
- 숫자, 공백 및 특수문자는 변경하지 않는다.
- 함수, 자료구조 및 라이브러리 사용에 별도의 제한은 없다.
