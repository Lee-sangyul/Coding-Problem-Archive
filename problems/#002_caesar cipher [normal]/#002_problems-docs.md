# #002 암호화 (Caesar Cipher)

**Difficulty: Normal | Language: Python, C**

## 문제 설명

나는 기존 문자열 암호화 시스템을 개선하는 업무를 맡고 있다.

기존 암호화 시스템에서는 알파벳을 양의 방향으로만 이동할 수 있었지만, 새로운 시스템에서는 음의 방향으로도 이동할 수 있어야 한다.

또한 이동하는 칸 수 m은 알파벳의 개수인 26보다 클 수 있다.

알파벳의 범위를 벗어나는 경우 순환하여 이동하며, 숫자, 공백 및 특수문자는 그대로 유지한다.

모든 제한사항을 준수하여 문자열을 암호화하는 프로그램을 작성하시오.

## 입력 설명

첫 번째 줄에 문자열의 길이 n과 이동하는 칸 수 m을 공백으로 구분하여 입력받는다.

두 번째 줄에 암호화할 문자열 S를 입력받는다.

## 출력 설명

문자열 S의 알파벳만 m칸씩 이동시켜 암호화한 결과를 출력한다.

## 제한사항

### 공통

- m은 양의 정수, 음의 정수 또는 0일 수 있다.
- 영문 알파벳의 대소문자를 유지한다.
- 숫자, 공백 및 특수문자는 변경하지 않는다.
- 문자를 한 칸씩 m번 이동시키는 방식은 사용할 수 없다.
- 암호화 기능은 반드시 sol() 함수로 구현한다.

### Python

- chr() 및 ord() 함수의 사용을 금지한다.

### C

- 문자 코드에 기반한 직접적인 산술 연산을 금지한다.
